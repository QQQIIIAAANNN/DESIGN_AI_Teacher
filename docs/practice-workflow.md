# 練習情境、模擬題與工作檔

審圖設定使用四種作圖情境：2–3 小時快速方案、4 小時敷地大圖、6 小時公務三級、8 小時完整設計大圖。每次可把作圖分鐘數調整為 60–600 分鐘；情境會連同應交圖說與完成度門檻送入分主題審圖和五項評分。短時練習仍核對題意、主入口及主要動線；沒有畫出的細部只能記為尚未證明。分數均為平台練習暫評。

「AI 生成練習題」支援建築設計、敷地與三級。模型會參考同類歷年索引，並盡量讀取兩份官方題目 PDF 的文字，再生成新的基地條件、機能、設計課題及應交圖說。可在「特殊練習需求」指定河岸、山坡地、人車分流等練習焦點。若官方 PDF 暫時無法讀取，題卡會顯示僅依題庫索引。考前猜題是練習推演，並非官方預測；題卡附有參考案例連結。生成題可直接作為當次審圖的題目條件。

新題的基地圖採黑白試題示意風格，包含指北、基地界線、尺寸、道路、鄰地、指定退縮與原有物。基地文字與 SVG 圖面從同一份結構化資料產生；圖面可單獨下載 SVG，也會隨生成題寫入工作檔。圖面為練習示意，尺寸以題目標註為準，並非官方試題或測量圖。

小型倒數計時器可開始、暫停與重設。匯出的 JSON 工作檔包含原始作答圖、上傳的題目 PDF、選用題目、審圖意見、確認位置、卡片討論及暫停後的剩餘時間。匯入後會還原這些資料；生成的局部修改圖需由各卡片另行下載。工作檔可能含私人圖面及題目內容，請存放於自己控制的私有位置。

每張審圖卡可展開對話框，模型會重新看該位置的局部圖與相關知識，並以串流方式逐步顯示回覆。只有局部圖能證明原判斷有誤時才修正卡片；分數會標為待重評。卡片對話與因對話產生的修正目前只保存在本機頁面及匯出工作檔，不會自動寫入雲端紀錄。
