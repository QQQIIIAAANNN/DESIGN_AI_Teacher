# 平台空間關係與圖面證據審查準則 v1

本文件是平台自訂的練習審圖準則，不代表考試主管機關的評分規定。每個判斷需同時顯示圖面或題目證據；看不清時列為待確認。

1. 以戶外、半戶外、室內的到達與停留序列檢查空間轉換。
2. 區分開放、半開放、半封閉、封閉，檢查邊界、視線與可達性。
3. 檢查公共、中介、私密梯度與不同使用者的交會。
4. 對照道路、鄰里紋理、朝向、基地邊界及題目目標檢查建築計畫。
5. 題名不是題目全文；沒有題目要求時，只能暫評符合度。
6. 對指北針、入口、車道坡道與階梯，先核對文字、標高與幾何，再下結論。
7. 分數與修改方向須能追溯到題目條件、知識單元與可見圖面證據。
8. 局部改善圖需保留原圖，將新增、拆除與註記分層表示。
9. 逐一對照題目目標、使用者需求、機能與設計概念在配置、平面、剖面的實際解答。
10. 環境控制需以朝向、開口、遮陽、通風與使用空間的可見關係為證據。
11. 綠化、水資源及其他永續主張需能定位其構件、空間效益與維護方式。
12. 柱網、核心、跨度與平剖關係只做構造合理性初查，不推定結構安全鑑定結果。
13. 無障礙與避難路徑可評連續性；法規合格或違規結論必須另有適用版本與可讀尺寸。
14. 有證據的優點應標明位置及保留理由，避免修改時破壞有效策略。
